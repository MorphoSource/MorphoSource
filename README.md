# MorphoSource

[MorphoSource](https://www.morphosource.org) is an open digital repository for 3D, 2D, and audiovisual media representing physical objects of scholarly interest, including biological specimens, fossils, cultural heritage objects, and more. It provides tools for uploading, managing, describing, and sharing media files, along with in-browser 3D viewing and a public REST API for programmatic access.

This repository contains the source code for the MorphoSource web application.

## Using MorphoSource

The live repository at **[www.morphosource.org](https://www.morphosource.org)** is freely available to researchers, educators, and the public. You can browse, view, and interact with openly shared media without an account, and register for a free account to download files or upload and manage your own contributions.

## Data and Vocabulary

MorphoSource uses a defined data vocabulary and ontology to describe specimens, media, and associated metadata. The vocabulary is documented at:

* [MorphoSource Data Vocabulary and Ontology Human-Readable Documentation](https://www.morphosource.org/terms/ms)
* [MorphoSource Data Vocabulary and Ontology Machine-Readable Repository](https://github.com/MorphoSource/data-vocabulary)
