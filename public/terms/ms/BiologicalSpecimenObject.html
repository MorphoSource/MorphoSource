Term Name ms:BiologicalSpecimenObject c

Term IRI http://www.morphosource.org/terms/ms/BiologicalSpecimenObject
Label Biological Specimen Object
Description

A physical object that is a biological specimen, such as a skeleton, a whole body, or a fossil.

Term Name dwc:country op

Term IRI http://rs.tdwg.org/dwc/terms/country
Label Country
Is Defined By http://rs.tdwg.org/dwc/terms/
Description

Recommended best practice is to use a controlled vocabulary such as the Getty Thesaurus of Geographic Names. Recommended best practice is to leave this field blank if the Location spans multiple entities at this administrative level or if the Location might be in one or another of multiple possible entities at this level. Multiplicity and uncertainty of the geographic entity can be captured either in the term higherGeography or in the term locality, or both.

The name of the country or major administrative unit in which the Location occurs.
Example 
`Denmark`, `Colombia`, `España`

Term Name dwc:occurrenceID dp

Term IRI http://rs.tdwg.org/dwc/terms/occurrenceID
Label Occurrence ID
Is Defined By http://rs.tdwg.org/dwc/terms/
Description

Recommended best practice is to use a persistent, globally unique identifier.

An identifier for the Occurrence (as opposed to a particular digital record of the occurrence). In the absence of a persistent global unique identifier, construct one from a combination of identifiers in the record that will most closely make the occurrenceID globally unique.

Term Name ms:canonicalTaxonomy dp

Term IRI http://www.morphosource.org/terms/ms/canonicalTaxonomy
Label Canonical Taxonomy
Description

MorphoSource-specific ID of Taxonomy record for taxonomic name attributed to the specimen physical object by the provider organization (museum, institution, or laboratory) responsible for managing the specimen. May not be present if no provider-supplied taxonomy is present. This may differ from taxonomic names attributed to the specimen by researchers or other individuals. Values for this property should be a subset of values for property morphosource:taxonomyID values, but morphosource:taxonomyID may include additional values as well.
Sub Property Of ms:ID
Value Restriction xsd:string
Type Datatype Property
