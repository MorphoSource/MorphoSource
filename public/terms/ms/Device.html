Term Name ms:modality3D op

Term IRI http://www.morphosource.org/terms/ms/modality3D
Label Modality
Description

The list of imaging modalities that a device is capable of using when imaging objects. Despite the name, this can include non-3D imaging event modalities. Value must be from Image Modality controlled vocabulary (http://www.morphosource.org/terms/ms/ImageModality).
Example 
`MicroNanoXRayComputedTomography`, `Photogrammetry`, `Video`
