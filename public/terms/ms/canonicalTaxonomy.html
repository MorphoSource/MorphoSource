Term Name ms:canonicalTaxonomy dp

Term IRI http://www.morphosource.org/terms/ms/canonicalTaxonomy
Label Canonical Taxonomy
Description

MorphoSource-specific ID of Taxonomy record for taxonomic name attributed to the specimen physical object by the provider organization (museum, institution, or laboratory) responsible for managing the specimen. May not be present if no provider-supplied taxonomy is present. This may differ from taxonomic names attributed to the specimen by researchers or other individuals. Values for this property should be a subset of values for property morphosource:taxonomyID values, but morphosource:taxonomyID may include additional values as well.
Sub Property Of ms:ID
Property Of ms:BiologicalSpecimenObject
Value Restriction xsd:string
Type Datatype Property
