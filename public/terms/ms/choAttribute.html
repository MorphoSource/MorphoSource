Term Name ms:choAttribute dp

Term IRI http://www.morphosource.org/terms/ms/choAttribute
Label Cultural Heritage Object Attribute
Description

Physical attributes of an object, including characteristics such as size and shape, chemical properties of materials, qualities of texture and hardness, and features such as surface ornament. It is preferred to use morphosource:aatAttribute when it is possible to express attributes using the Getty Arts and Architecture Thesaurus controlled vocabulary. This property is for custom attribute values not listed in the Getty AAT controlled vocabulary.
