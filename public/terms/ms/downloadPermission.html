Term Name ms:downloadPermission op

Term IRI http://www.morphosource.org/terms/ms/downloadPermission
Label Download Permission
Description

Preferred Publication Status (morphosource:visibility) for Media representing Organization Physical Objects. Value must be from Publication Status controlled vocabulary (http://www.morphosource.org/terms/ms/PublicationStatus).
Example 
`Open`, `Restricted`, `Private`
Property Of ms:Organization
Value Restriction mscv:PublicationStatus
